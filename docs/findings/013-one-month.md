## 斷言用的是兩個整數，不是畫面

```go
year, _  := o.Long(0x7A150)   // docs/formats/03，L1
month, _ := o.Long(0x7A158)   // 同上，L2
if year != 189 || month != 2 { … }
```

畫面比對要 128 KB；「189 年 1 月 → 189 年 2 月」是兩個整數。
**能用便宜的斷言就不要用貴的**——貴的斷言會讓人不想跑。

（畫面比對仍然重要，但它的角色是 M3 的驗收，不是「跑到哪裡了」的判準。）
