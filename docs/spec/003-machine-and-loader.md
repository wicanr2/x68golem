# 003 — 機器與載入器

狀態：**DRAFT**（2026-09-05）

## 記憶體配置

| 區 | 位址 |
|---|---|
| 主記憶體 | `0x000000–` （容量可設，預設 2 MB）|
| graphics VRAM | `0xC00000` |
| text VRAM（四平面）| `0xE00000`／`0xE20000`／`0xE40000`／`0xE60000` |
| CRTC／video controller／調色盤／DMAC／MFP／FDC | `0xE8xxxx`–`0xEBxxxx` |
| CGROM | `0xF00000–` （玩家自備）|
| IPL ROM | `0xFE0000–` （玩家自備）|

依據：`SANMAIN.Z` 的絕對位址運算元普查（`sangokushi_x68k_cht` 的
`docs/design/06` §4.1(c)）——落在 `0xC00000` 以上的只有上表這幾類。
⚠ 那份普查只抓得到**絕對位址運算元**，基底存在變數裡再間接寫的抓不到，
**是下界不是全部**。`cmd/probe` 存在就是為了在執行期把漏掉的喊出來。

## `.Z` 載入器

Human68k 的 `.Z` 是**固定位址的平坦映像，沒有重定位表**：
檔頭 `$16` 是執行起始位址，映像第一個 byte 就放在那個位址
（`sangokushi_x68k_cht` 的 `docs/re/01`，L1）。

所以載入器很短：讀檔頭、把 text＋data 放到基底、bss 清 0、設堆疊、跳進去。
**沒有換算，也就不提供換算介面**（`006`）。
